# سند تفصیلی پورتفولیو و معماری پروژه‌ها (P0 تا P6)
### مشخصات فنی، معماری لایه‌ای، معیارهای قبولی و مزیت رقابتی

---

## مقدمه: فلسفه ساخت پورتفولیو در دنیای واقعی هوش مصنوعی
کارفرمایان بین‌المللی و شرکت‌های پیشرو دیگر با پروژه‌های اسباب‌بازی (Toy Projects) مانند «تحلیل دیتاست تایتانیک» یا «یک چت‌بات ساده با یک پرامپت استاتیک» تحت تأثیر قرار نمی‌گیرند. چیزی که یک مهندس واقعی را متمایز می‌کند، **شواهد مهندسی (Engineering Evidence)** است:
۱. کد تمیز با تست خودکار و خط لوله CI/CD
۲. در نظر گرفتن هزینه‌ها، امنیت و تاخیر (Latency)
۳. ارزیابی عددی و بنچ‌مارک (Evaluation Metrics)
۴. حل یک مسئله واقعی برای یک کاربر واقعی

پروژه‌های زیر به نحوی طراحی شده‌اند که روی سیستم قدرتمند شما (**i9-14900KF + RTX 3090 24GB VRAM**) با بالاترین پرفورمنس و به شکل کاملاً محلی (Local-First) اجرا شوند.

---

## پروژه P0: سرویس بک‌اند ماژولار و پروداکشن پایتون (Production Python API)
- **زمان اجرا:** هفته ۱ تا ۸
- **پشته فناوری (Stack):** Python 3.12, FastAPI, Pydantic v2, PostgreSQL, SQLAlchemy 2.0 / asyncpg, Docker & Docker-Compose, Pytest, Ruff, GitHub Actions.
- **معماری:** معماری تمیز و لایه‌ای (Router -> Service -> Repository -> Database Model).
- **قابلیت‌های کلیدی:**
  ۱. پیاده‌سازی کامل CRUD برای مدیریت وظایف با احراز هویت مبتنی بر JWT / API Key.
  ۲. مهاجرت خودکار پایگاه داده با Alembic.
  ۳. سیستم لاگین ساختاریافته (Structured JSON Logging) و مدیریت متمرکز استثناها.
  ۴. پوشش تست بالای ۸۰٪ با تست‌های Unit و Integration در محیط ایزوله داکر.
  ۵. فایل Dockerfile بهینه‌شده چندمرحله‌ای (Multi-stage build).
- **تعریف انجام کار (Definition of Done):**
  - با یک دستور docker compose up --build کل سیستم بالا بیاید.
  - تست‌های گیت‌هاب اکشنز سبز شوند.
  - مستندات OpenAPI در آدرس /docs به صورت کامل نمایش داده شوند.

## پروژه P1: موتور پیش‌بینی و سرویس یادگیری ماشین پروداکشن (Production ML Engine)
- **زمان اجرا:** هفته ۹ تا ۱۶
- **پشته فناوری (Stack):** Scikit-Learn, XGBoost, Pandas, NumPy, FastAPI, Joblib, Pytest, Docker.
- **مسئله:** پیش‌بینی یک مسئله تجاری ملموس (مانند پیش‌بینی تقاضا، برآورد قیمت یا دسته‌بندی ریسک کاربر).
- **قابلیت‌های کلیدی:**
  ۱. خط لوله تمیز پیش‌پردازش داده‌ها (Scikit-Learn Pipeline) بدون نشت اطلاعات (Data Leakage).
  ۲. پیاده‌سازی چند مدل (Baseline Logistic/Linear Regression در مقابل Random Forest و XGBoost) و مقایسه دقیق متریک‌ها.
  ۳. اعتبارسنجی متقاطع (Stratified K-Fold Cross-Validation).
  ۴. مستند رسمی شناسنامه مدل (Model Card Markdown) شامل شرح دیتاست، محدودیت‌ها و سوگیری‌ها.
  ۵. سرویس‌دهی پیش‌بینی‌ها از طریق REST API با زمان پاسخ کمتر از ۵۰ میلی‌ثانیه.
- **تعریف انجام کار (Definition of Done):**
  - ورودی‌های کاربر توسط Pydantic اعتبارسنجی شوند.
  - خط لوله پیش‌پردازش همراه مدل ذخیره و در یک گام لود شود.
  - جدول ارزیابی مدل و بنچ‌مارک در README ریپازیتوری منتشر شود.

## پروژه P2: سیستم RAG سازمانی با ارزیابی و استناد دقیق (Enterprise Evidence-Grounded RAG)
- **زمان اجرا:** هفته ۱۷ تا ۳۲
- **پشته فناوری (Stack):** Local LLMs (Llama 3.1 / Qwen 2.5 via Ollama/vLLM on RTX 3090 24GB), Sentence-Transformers (BAAI/bge-m3), Qdrant / ChromaDB, Ragas, FastAPI.
- **مزیت اختصاصی:** استفاده از ۲۴ گیگابایت VRAM گرافیک RTX 3090 برای اجرای مدل‌های قدرتمند به صورت کاملاً آفلاین و رایگان بدون وابستگی به APIهای پولی خارجی.
- **قابلیت‌های کلیدی:**
  ۱. قطعه‌بندی هوشمند اسناد (Context-Aware Semantic Chunking).
  ۲. بازیابی هیبریدی (Hybrid Search): ترکیب جستجوی متنی کلمات کلیدی (BM25) با جستجوی معنایی برداری (Dense Vector Search).
  ۳. رتبه‌بندی مجدد (Reranking) نتایج با مدلی سبک مانند BGE-Reranker برای حذف نتایج بی‌ربط.
  ۴. گاردریل استناد به منبع (Citation Grounding): مدل مجاز نیست ادعایی کند مگر آنکه شماره صفحه، خط یا پاراگراف سند را ارجاع دهد.
  ۵. چارچوب ارزیابی اتوماتیک با ابزار Ragas: ارزیابی ۱۰۰ سؤال استاندارد بر اساس شاخص‌های Faithfulness و Answer Relevance.
  ۶. دفاع در برابر تزریق پرامپت (Prompt Injection Defense).
- **تعریف انجام کار (Definition of Done):**
  - امتیاز Faithfulness بالای ۸۵٪ در بنچ‌مارک ۱۰۰ سؤاله.
  - مستند تست‌های استرس و مصرف رم/گرافیک روی سیستم.

## پروژه P3: گردش کار ایجنتی و سرور MCP (Agentic AI Workflow & MCP Server)
- **زمان اجرا:** هفته ۳۳ تا ۴۰
- **پشته فناوری (Stack):** Python, Anthropic/OpenAI SDKs or Local Tool-Calling LLMs, Model Context Protocol (MCP), SQLite/PostgreSQL, Rich/CLI.
- **رویکرد ساختاری:** شروع با لوپ دستی ابزارها (Manual Tool Loop) برای درک صفر تا صد مکانیزم Tool Use قبل از رفتن سراغ فریم‌ورک‌ها.
- **قابلیت‌های کلیدی:**
  ۱. پیاده‌سازی الگوریتم تفکر ReAct (Reasoning + Acting) بدون فریم‌ورک‌های سنگین جادویی.
  ۲. ساخت سرور اختصاصی پروتکل کانتکست مدل (Model Context Protocol - MCP) که به ابزارهای سیستمی (دیتابیس، فایل‌ها، ماشین‌حساب، جستجو) متصل می‌شود.
  ۳. مکانیزم تایید انسانی در حلقه (Human-in-the-Loop - HITL) برای عملیات‌های مخرب و حساس (مانند حذف فایل یا ارسال تراکنش).
  ۴. سیستم مدیریت وضعیت و حافظه پایدار (Stateful Memory & Session Handling).
- **تعریف انجام کار (Definition of Done):**
  - تست‌های Integration تایید کنند ایجنت در مواجهه با خطای ابزار کرش نمی‌کند بلکه خطا را بازبینی و تصحیح می‌کند.
  - سرور MCP در کلاینت‌های استاندارد تست و اجرا شود.

## پروژه P4: دستیار هوشمند جستجو و تحلیل چندرسانه‌ای (Multimodal Media Search Assistant)
- **زمان اجرا:** هفته ۴۱ تا ۴۸
- **پشته فناوری (Stack):** Python, FFmpeg, Whisper (Faster-Whisper on RTX 3090), OpenCV, CLIP / SigLIP, Qdrant Vector DB, FastAPI.
- **مزیت اختصاصی فربد:** اهرم کردن تخصص و پیشینه شما در **گرافیک، ویدیو و تدوین** برای ساخت پروژه‌ای که ۹۹٪ متقاضیان عادی هوش مصنوعی قادر به ساخت آن نیستند!
- **قابلیت‌های کلیدی:**
  ۱. پایپ‌لاین بارگذاری ویدیو: استخراج متادیتا، تفکیک استریم‌های صوتی و تصویری با FFmpeg.
  ۲. تشخیص فریم‌های کلیدی و تغییر صحنه (Scene Cut Detection) با استفاده از OpenCV.
  ۳. تبدیل گفتار به متن فوق‌سریع با Whisper روی GPU و استخراج زیرنویس دارای Timecode دقیق ثانیه‌ای.
  ۴. امبدینگ فریم‌های بصری با مدل CLIP/SigLIP برای ایجاد قابلیت Text-to-Video Search (مثال: کاربر سرچ می‌کند «صحنه‌ای که ماشین قرمز ترمز می‌کند» و دقیقاً ثانیه مورد نظر پیدا می‌شود).
  ۵. نمایش خروجی همراه با تایم‌کد، تصویر بندانگشتی (Thumbnail) و پیش‌نمایش ویدیو.
- **تعریف انجام کار (Definition of Done):**
  - پشتیبانی از فرمت‌های MP4, MKV, MP3.
  - ایندکس کامل یک ویدیوی ۱ ساعته در کمتر از ۵ دقیقه روی کارت گرافیک RTX 3090.
  - امکان پخش ویدیو دقیقاً از ثانیه مشخص‌شده در مرورگر.

## پروژه P5: پایلوت با کاربر واقعی و لاگین مانیتورینگ (Real-World Pilot & Observability)
- **زمان اجرا:** هفته ۴۹ تا ۵۲
- **هدف:** تبدیل یکی از پروژه‌های P2, P3 یا P4 به یک ابزار زنده با کاربر واقعی جهت ایجاد **شواهد واقعی صنعتی (Industrial Evidence)** برای رزومه.
- **الزامات:**
  ۱. تحویل نرم‌افزار به حداقل ۲ کاربر واقعی (هم‌دانشگاهی، همکار، تیم محتوایی یا یک کسب‌وکار کوچک).
  ۲. راه‌اندازی مانیتورینگ سلامت سرویس و ذخیره لاگ پرامپت‌ها و خروجی‌ها.
  ۳. مصاحبه و جمع‌آوری بازخورد کیفی و کمی (به عنوان مثال: زمان جستجوی ویدیو از ۱۵ دقیقه به ۳۰ ثانیه کاهش یافت).
  ۴. نگارش گزارش فنی پست‌مورتم (Engineering Postmortem): چه مشکلاتی در استفاده واقعی پیش آمد؟ چه تصمیماتی برای پایداری سرویس گرفته شد؟

## پروژه P6: تکرار آزمایش پژوهشی یا مشارکت در پروژه متن‌باز (Open Source / Research Reproduction)
- **زمان اجرا:** ماه ۱۳ تا ۱۸
- **هدف:** تقویت رزومه برای اپلای مقاطع عالی (MSc Thesis / Research Assistant) یا استخدام در شرکت‌های تراز اول بین‌المللی.
- **خروجی:**
  - گزینه الف: انتخاب یک مقاله معتبر ۲۰۲۴-۲۰۲۶ در حوزه بازیابی اطلاعات (Retrieval) یا چندرسانه‌ای و بازتولید کدهای آن با گزارش فنی ۴ تا ۶ صفحه‌ای استاندارد.
  - گزینه ب: ارسال حداقل یک Pull Request معتبر که در یکی از ابزارهای شناخته‌شده اکوسیستم هوش مصنوعی (مثل LangChain, Qdrant, LlamaIndex, Transformers یا ابزارهای پایتونی) مرج شود.
