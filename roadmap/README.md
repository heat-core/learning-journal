## 💻 مشخصات زیرساخت سخت‌افزاری (Hardware Advantage)
سیستم توسعه شما از پتانسیل فوق‌العاده‌ای برای اجرای پروژه‌های مدرن هوش مصنوعی برخوردار است:
- **پردازنده (CPU):** Intel Core i9-14900KF (قدرت پردازش موازی بالا برای دیتا پایپ‌لاین‌ها و کامپایل کد)
- **کارت گرافیک (GPU):** NVIDIA GeForce RTX 3090 با **۲۴ گیگابایت VRAM اختصاصی** (ایده‌آل برای اجرای مدل‌های محلی Llama 3 / Qwen، امبدینگ‌های سنگین، فاین‌تیون و استنتاج بدون هزینه کلود)
- **حافظه رم (RAM):** ۳۲ گیگابایت (کافی برای پردازش حجم‌های بالای دیتافریم و کشینگ داکر)
